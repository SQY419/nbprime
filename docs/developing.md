# 按键事件

## 两种取键方式的区别

| 方式 | 返回 | 无按键时 |
|---|---|---|
| PPL `GETKEY` | 单个键码（事件） | **-1** |
| hpprime `keyboard()`（Python） | 当前按下键的**位掩码** | **0**（无任何位） |

`keyboard()` 的位号与 `GETKEY` 键码**完全一致**：`keyboard() & (1 << N)` 为真 ⇔ 键码 N 正被按下。
